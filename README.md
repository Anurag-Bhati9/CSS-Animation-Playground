# CSS Animation Playground 🎨

A simple **HTML & CSS animation playground** created to practice and demonstrate different CSS animation techniques.

The project showcases multiple animated shapes and elements, each demonstrating a different CSS animation effect, including **color transitions, movement, rotation, pulsing, fading, spinning, wave motion, and border animation**.

## ✨ Features

* 🎨 **Color Animation** — Demonstrates animated color transitions using `@keyframes`
* ↕️ **Move Animation** — Demonstrates horizontal/vertical movement
* 🔄 **Rotate Animation** — Demonstrates element rotation using `transform`
* 💓 **Pulse Animation** — Creates a pulsing effect by changing scale
* 🌫️ **Fade Animation** — Demonstrates opacity-based fading
* 🌀 **Spin Animation** — Creates continuous spinning motion
* 🌊 **Wave Animation** — Demonstrates wave-like movement
* ⬜ **Border Movement** — Animates borders using custom keyframes

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **CSS `@keyframes`**
* **CSS `transform`**
* **CSS animations**

No external libraries or frameworks are required.

## 🎯 Animations Demonstrated

The project demonstrates the following CSS `@keyframes` animations:

```css
@keyframes color
@keyframes move
@keyframes rotate
@keyframes pulse
@keyframes fade
@keyframes spin
@keyframes wave
@keyframes move-border
```

Each animation demonstrates a different way CSS can be used to create movement and visual effects without JavaScript or external animation libraries.
